# Fuel Economy Map

Адаптивная система топливной экономии на основе OBD-II данных.

## Цель
Построить обучаемую 2D-карту эффективности двигателя (RPM × Load) и давать рекомендации по оптимальным оборотам / переключению передач.

## Структура
- `data/ved` — датасет VED (публичные логи)
- `data/own` — собственные логи с машин
- `notebooks` — исследование данных
- `src` — код

## Статус
Этап 0: исследование данных VED + оценка реалистичности идеи.
